# 🎓 Graduate Employment Analysis in Singapore (2020–2023)

This Power BI dashboard explores graduate employment trends across Singapore’s autonomous universities using data from the MOE Graduate Employment Survey.

## 📊 Key Questions Answered:

- How have graduate salaries changed from 2020–2023?
- Which universities have the highest or most stable salary growth?
- How consistent is graduate employment across institutions?
- Which degrees show the most variability in graduate outcomes?

---

## 🧩 Dashboard Features

✅ **Line Chart**: Median Monthly Salary Trend (2020–2023)  
✅ **Bar Chart**: Employment Rate Comparison  
✅ **Scatter Plot**: Salary Range vs Median by Degree  
✅ **Waterfall Chart**: Salary Variability by University  

> Includes interactive filters by year, university, and degree.

## 📌 Insights Summary

- 📈 **SMU** shows the highest median salary growth, exceeding SGD $5,000 in 2023  
- 🧑‍🎓 **All universities maintain ~95% employment rate**, even post-COVID  
- 💼 **High variability in salaries** among degrees such as Business and Tech  
- 🔍 **Scatter plot** shows which degrees have widest salary distributions
